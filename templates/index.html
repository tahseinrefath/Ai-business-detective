Good questions

Does the AI make up causes?

No. Python and pandas do every calculation. The explanation only describes those numbers, and it states that a contributor shows where a change happened, not proof of why.

Which file types work, and what are the limits?

Excel, CSV/TSV, JSON and OpenDocument work best. PDFs must contain real text tables — scanned images cannot be read. Power BI .pbix files work when the data is imported into the file; live-connection or DirectQuery reports hold no data, so export a table to CSV/Excel instead.

Is my data uploaded anywhere?

No. The app runs on your own computer and stores cleaned data in a local folder. An optional LLM key sends only calculated summary figures — never raw rows.

What if my latest month is incomplete?

The app detects partial months and warns you, so a half-finished month isn't mistaken for a real decline.

What does the forecast mean?

It extends the monthly trend in a straight line. It is a rough guide, not a prediction, and is labelled that way.
